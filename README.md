# DSA Implementations

A collection of simple C++ implementations for learning data structures and algorithms.

## Repository Structure

```text
DSA-Implementations/
|-- 01_ARRAYS/
|-- 02_LINKED_LISTS/
|-- 03_STACKS_AND_QUEUES/
`-- README.md
```

## Array Programs

| File | Description | Time Complexity | Space Complexity |
|---|---|---|---|
| `00_Array_traversal_and_stats.cpp` | Print an array and calculate sum and average | O(n) | O(1) |
| `01_Max_and_min_element.cpp` | Find maximum and minimum values | O(n) | O(1) |
| `02_Second_largest_element.cpp` | Find the second largest element in one pass | O(n) | O(1) |
| `03_Reverse_array.cpp` | Reverse an array in-place using two pointers | O(n) | O(1) |
| `04_Odd_and_even_count.cpp` | Count and separate odd and even elements | O(n) | O(1) |
| `05_Remove_duplicates_sorted.cpp` | Remove duplicates from a sorted array in-place | O(n) | O(1) |
| `06_Rotate_array_by_k.cpp` | Left-rotate an array by k positions | O(n * k) | O(1) |
| `07_Linear_search.cpp` | Search for a value using linear search | O(n) | O(1) |
| `08_Binary_search.cpp` | Search a sorted array with iterative binary search | O(log n) | O(1) |
| `09_Bubble_sort.cpp` | Sort using optimized bubble sort | O(n^2), O(n) when already sorted | O(1) |
| `10_Selection_sort.cpp` | Sort using selection sort | O(n^2) | O(1) |
| `11_Insertion_sort.cpp` | Sort using insertion sort | O(n^2) | O(1) |
| `12_Merge_sort.cpp` | Sort recursively using merge sort | O(n log n) | O(n) |
| `13_Quick_sort.cpp` | Sort recursively using quick sort | O(n log n) average, O(n^2) worst | O(log n) average, O(n) worst |
| `14_Dynamic_array_pointers.cpp` | Allocate and release a dynamic array using pointers | O(n) | O(n) |
